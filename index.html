把绘梨衣放在桌面上

一个会走动、会说话、会记住你的桌面陪伴。点一下头像能开关声音、翻她的记忆； 打开对话窗可以聊天，也可以开视频通话——她说话时桌宠会停下来看着你。

安装后能做什么

桌宠

待机 / 走动 / 转身 / 吃东西，右键菜单打开对话或视频通话，她在说话时会站定。

对话与通话

对话窗跑在同一个进程里；通话窗点「开始通话」才开麦，挂断释放麦克风。

记忆星云

她说记住的事会变成星云里的星星，可悬停查看、点开删除，Ctrl+Shift+M 直接打开。

头像菜单

点头像：视频通话 / 更换性格 / 记忆 / 声音 / 设置，和底部 chip 保持同步。

「在网页启动桌宠」怎么用

先装桌面版并**至少启动过一次**，之后点这个按钮，浏览器会通过 eripet:// 唤起本机应用， 和你从桌面双击启动完全一样。
没装的话点按钮不会有反应，按提示下载安装包即可。

装不上？先看这里

1. 提示「Windows 已保护你的电脑」：安装包没有代码签名，点「更多信息 → 仍要运行」。
2. 双击没反应 / 被拦截：可能是 360 等杀软拦了，先把文件加入信任，或用免安装版。
3. 提示不是有效的 Win32 程序：这台电脑是 32 位系统，本应用只支持 64 位 Windows 10/11。
4. 下载到一半失败：文件约 120~132 MB，重新下载后可用下方 SHA256 校验完整性。
5. 装完打不开：先试免安装版；仍不行把报错截图发到仓库 Issues。

「网页视频通话」怎么用

这个按钮打开的是本机语音服务提供的网页（http://127.0.0.1:8890/ui）： 她的脸、字幕、音量律动在浏览器里，麦克风采集和放音仍然由本机服务做， 所以效果和桌面版通话窗完全一致。
前提：本机语音服务在跑（双击 启动通话服务.cmd，或开机自启）。 没跑的话页面打不开，回到「下载安装包」安装后由安装包自带的语音服务提供。

关于语音

桌宠、对话、记忆星云、头像互动、视频通话界面都随安装包提供，换电脑即装即用。
但她的声音来自本机的 GPT-SoVITS 语音服务（模型体积在 GB 级、依赖显卡）， 没有随安装包分发。所以在新电脑上：
· 文字对话、记忆、桌宠动作 = 开箱即用
· 语音通话 = 需要另外部署语音服务，或在设置里配置支持语音的云端接口
