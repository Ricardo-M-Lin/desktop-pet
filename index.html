WINDOWS · 桌面陪伴

把绘梨衣放在桌面上

一个会走动、会说话、会记住你的桌面陪伴。点一下头像能开关声音、翻她的记忆； 打开对话窗可以聊天，也可以开视频通话——她说话时桌宠会停下来看着你。

下载安装包（Windows）
安装包约 132 MB，含桌宠本体、对话窗与记忆星云。

安装后能做什么

桌宠

待机 / 走动 / 转身 / 吃东西，右键菜单打开对话或视频通话，她在说话时会站定。

对话与通话

对话窗跑在同一个进程里；通话窗点「开始通话」才开麦，挂断释放麦克风。

记忆星云

她说记住的事会变成星云里的星星，可悬停查看、点开删除，Ctrl+Shift+M 直接打开。

头像菜单

点头像：视频通话 / 更换性格 / 记忆 / 声音 / 设置，和底部 chip 保持同步。

「在网页启动桌宠」怎么用

先装桌面版并**至少启动过一次**，之后点这个按钮，浏览器会通过 eripet:// 唤起本机应用， 和你从桌面双击启动完全一样。
没装的话点按钮不会有反应，按提示下载安装包即可。

关于语音

桌宠、对话、记忆星云、头像互动、视频通话界面都随安装包提供，换电脑即装即用。
但她的声音来自本机的 GPT-SoVITS 语音服务（模型体积在 GB 级、依赖显卡）， 没有随安装包分发。所以在新电脑上：
· 文字对话、记忆、桌宠动作 = 开箱即用
· 语音通话 = 需要另外部署语音服务，或在设置里配置支持语音的云端接口
